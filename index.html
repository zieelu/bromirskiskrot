NAT + DNAT

RTR wprowadzamy
echo 1 > /proc/sys/net/ipv4/ip_forward
iptables -t nat -F
iptables -F
iptables -t nat -A POSTROUTING -s 10.41.12.0/24 -o eth2 -j MASQUERADE
iptables -A FORWARD -i eth1 -o eth2 -j ACCEPT
iptables -A FORWARD -i eth2 -o eth1 -m state --state ESTABLISHED,RELATED -j ACCEPT
-- sprawdź pingi vm01
ustawiamy DNat
iptables -t nat -A PREROUTING -i eth2 -p tcp --dport 3301 -j DNAT --to 10.41.12.201:22
iptables -t nat -A PREROUTING -i eth2 -p tcp --dport 1102 -j DNAT --to 10.41.12.202:22
iptables -t nat -A PREROUTING -i eth2 -p tcp --dport 5011 -j DNAT --to 10.41.12.201:80
iptables -t nat -A PREROUTING -i eth2 -p tcp --dport 8762 -j DNAT --to 10.41.12.202:80

DHCP / VM03

vmo3 dhcp
na RTR
apt install isc-dhcp-server -y

nano /etc/dhcp/dhcpd.conf -tego nie trzeba
wpisz w konsole:

cat > /etc/dhcp/dhcpd.conf <<'EOF'
default-lease-time 600;
max-lease-time 7200;
authoritative;

subnet 10.41.12.0 netmask 255.255.255.0 {
range 10.41.12.100 10.41.12.150;
option routers 10.41.12.254;
option domain-name-servers 10.41.12.254;
}
EOF

nastepniee: nano /etc/default/isc-dhcp-server
zmień:

INTERFACESv4=""

na:

INTERFACESv4="eth1"

zapisz i wykonaj:

systemctl restart isc-dhcp-server
systemctl status isc-dhcp-server

I w sumie powinno działacc zaloguj się na vm03 i zobacz

ip a
nmcli con show
powinien bycc przydzielony adres z dhcp

Nginx - wersja klasyczna

zadanie 2 na Nginx wyglądałoby prawie tak samo, tylko zamiast Apache VirtualHostów robisz server blocki.

VM01

apt update
apt install nginx -y
systemctl enable nginx
systemctl restart nginx

echo "VM01" > /var/www/html/index.html

mkdir -p /var/www/12.net
mkdir -p /var/www/122921.student.san.edu.pl

echo "VM01 - 12.net" > /var/www/12.net/index.html
echo "VM01 - 122921.student.san.edu.pl" > /var/www/122921.student.san.edu.pl/index.html

cat > /etc/nginx/sites-available/12.net <<'EOF'
server {
listen 80;
server_name 12.net;
root /var/www/12.net;
index index.html;
}
EOF

cat > /etc/nginx/sites-available/122921.student.san.edu.pl <<'EOF'
server {
listen 80;
server_name 122921.student.san.edu.pl;
root /var/www/122921.student.san.edu.pl;
index index.html;
}
EOF

ln -s /etc/nginx/sites-available/12.net /etc/nginx/sites-enabled/
ln -s /etc/nginx/sites-available/122921.student.san.edu.pl /etc/nginx/sites-enabled/

nginx -t
systemctl reload nginx

Test:

curl http://localhost
curl -H "Host: 12.net" http://localhost
curl -H "Host: 122921.student.san.edu.pl" http://localhost

KOMENDY

Najczęściej używane komendy Linux — szybka ściąga do poruszania się po systemie, edycji plików, sieci i diagnostyki VM.

Poruszanie się po katalogach

pwd

Pokazuje aktualny katalog, w którym teraz jesteś.

ls

Pokazuje pliki i foldery w aktualnym katalogu.

ls -l

Pokazuje pliki w formie szczegółowej: uprawnienia, właściciel, rozmiar i data.

ls -la

Pokazuje szczegółową listę razem z plikami ukrytymi, czyli zaczynającymi się od kropki.

cd /etc

Przechodzi do katalogu /etc, gdzie często są pliki konfiguracyjne.

cd ..

Cofa o jeden katalog wyżej.

cd ~

Przechodzi do katalogu domowego aktualnego użytkownika.

cd /

Przechodzi do głównego katalogu systemu.

Tworzenie i usuwanie plików/katalogów

mkdir nazwa

Tworzy nowy katalog o podanej nazwie.

mkdir -p /var/www/12.net

Tworzy cały katalog wraz z brakującymi katalogami po drodze.

touch plik.txt

Tworzy pusty plik albo aktualizuje datę istniejącego pliku.

rm plik.txt

Usuwa wskazany plik.

rm -r katalog

Usuwa katalog razem z zawartością.

cp plik kopia

Kopiuje plik do nowej lokalizacji albo pod nową nazwą.

mv stara_nazwa nowa_nazwa

Zmienia nazwę pliku albo przenosi plik do innego katalogu.

Wyszukiwanie plików i tekstu

find / -name "interfaces"

Szuka pliku o nazwie interfaces w całym systemie.

find /etc -name "*.conf"

Szuka plików konfiguracyjnych z końcówką .conf w katalogu /etc.

find / -name "*.cfg"

Szuka plików z końcówką .cfg w całym systemie.

grep -R "10.41.12.254" /etc

Szuka tekstu 10.41.12.254 we wszystkich plikach w katalogu /etc.

history | grep iptables

Przeszukuje historię komend i pokazuje wcześniejsze komendy z iptables.

Wyświetlanie zawartości plików

cat plik.txt

Wyświetla całą zawartość pliku w terminalu.

less plik.txt

Otwiera plik do wygodnego przewijania. Wyjście: klawisz q.

head plik.txt

Pokazuje początek pliku.

tail plik.txt

Pokazuje końcówkę pliku.

tail -f /var/log/syslog

Pokazuje logi na żywo, przydatne przy diagnozie usług.

Edycja plików

nano /etc/network/interfaces

Otwiera plik konfiguracji sieci w edytorze nano.

CTRL + O

Zapisuje plik w nano.

ENTER

Potwierdza nazwę pliku podczas zapisu w nano.

CTRL + X

Wychodzi z edytora nano.

Sieć i diagnostyka

ip a

Pokazuje interfejsy sieciowe i przypisane adresy IP.

ip route

Pokazuje trasę domyślną i tablicę routingu.

ping 10.41.12.254

Sprawdza połączenie z routerem RTR w sieci LAN.

ping 8.8.8.8

Sprawdza, czy działa wyjście do Internetu po IP.

nslookup google.com

Sprawdza, czy działa rozwiązywanie nazw DNS.

curl http://localhost

Testuje lokalny serwer WWW na danej maszynie.

curl -H "Host: 12.net" http://localhost

Testuje VirtualHost/ServerName dla konkretnej domeny.

ss -tulpn

Pokazuje otwarte porty i usługi nasłuchujące na systemie.

Usługi systemowe

systemctl status apache2

Sprawdza status usługi Apache.

systemctl restart apache2

Restartuje Apache po zmianach konfiguracji.

systemctl status nginx

Sprawdza status usługi Nginx.

Restartuje konfigurację sieci.

systemctl restart haproxy

Restartuje HAProxy po zmianie konfiguracji.

systemctl restart ssh

Restartuje SSH po zmianach w sshd_config.

systemctl enable apache2

Ustawia Apache, aby startował automatycznie po uruchomieniu systemu.

Uprawnienia, użytkownik i pakiety

whoami

Pokazuje, jako jaki użytkownik jesteś zalogowany.

sudo su

Przełącza na konto root, jeśli użytkownik ma uprawnienia sudo.

chmod 644 plik

Ustawia typowe uprawnienia dla pliku tekstowego lub konfiguracyjnego.

chown root:root plik

Ustawia właściciela i grupę pliku na root.

apt update

Odświeża listę pakietów z repozytoriów.

Instaluje Apache bez pytania o potwierdzenie.

apt install nginx -y

Instaluje Nginx bez pytania o potwierdzenie.
