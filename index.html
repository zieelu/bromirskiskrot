Rezerwacja adresu DHCP dla VM03 — wariant POD112

Na VM03 sprawdź adres MAC interfejsu eth1. W tym przykładzie:

00:15:5d:04:49:ea

Na RTR otwórz konfigurację DHCP:

nano /etc/dhcp/dhcpd.conf

Na końcu pliku dopisz:

host vm03 {
    hardware ethernet 00:15:5d:04:49:ea;
    fixed-address 10.100.112.245;
}

Uwaga: adres rezerwacji musi należeć do tej samej podsieci, którą obsługuje DHCP. Dla tego przykładu POD112 jest to 10.100.112.0/24.

Sprawdź składnię i zrestartuj usługę:

dhcpd -t -cf /etc/dhcp/dhcpd.conf
systemctl restart isc-dhcp-server

VM03 — przełączenie eth1 na DHCP

nmtui

Wejdź w Edit a connection → eth1 i ustaw IPv4 na Automatic. Zapisz przez OK i wyjdź.

Następnie:

systemctl restart NetworkManager
ip a

VM03 powinna dostać zarezerwowany adres 10.100.112.245.

Jeżeli korzystasz z głównego vhosta, otwórz:

i zmień początek na:

Jeżeli masz inne aktywne VirtualHosty, które mają działać jako backend, w nich również zmień *:80 na *:800.

nano /etc/nginx/sites-available/default

Ustaw poprawnie port dla IPv4 i IPv6:

listen 1820 default_server;
listen [::]:1820 default_server;

Sprawdzenie i przeładowanie:

nginx -t
systemctl reload nginx
ss -lntp | grep :1820

Poprawka: w pierwszej linii nie może być listen [::]1820. Dla IPv4 ma być listen 1820, a dla IPv6 listen [::]:1820.

apt update

nano /etc/nginx/sites-available/balancer

Wklej:

upstream web_backend {
    server 10.100.112.11:800;
    server 10.100.112.12:800;
}

server {
    listen 78;

    location / {
        proxy_pass http://web_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;

Dodałem X-Forwarded-For, żeby backend dostał również poprawny łańcuch adresów klienta.

cat plik.txt

Wyświetla całą zawartość pliku w terminalu.

less plik.txt

Otwiera plik do wygodnego przewijania. Wyjście: klawisz q.

head plik.txt

Pokazuje początek pliku.

tail plik.txt

Pokazuje końcówkę pliku.

tail -f /var/log/syslog

Pokazuje logi na żywo, przydatne przy diagnozie usług.

Edycja plików

nano /etc/network/interfaces

Otwiera plik konfiguracji sieci w edytorze nano.

CTRL + O

Zapisuje plik w nano.

ENTER

Potwierdza nazwę pliku podczas zapisu w nano.

CTRL + X

Wychodzi z edytora nano.

Sieć i diagnostyka

ip a

Pokazuje interfejsy sieciowe i przypisane adresy IP.

ip route

Pokazuje trasę domyślną i tablicę routingu.

ping 10.41.12.254

Sprawdza połączenie z routerem RTR w sieci LAN.

ping 8.8.8.8

Sprawdza, czy działa wyjście do Internetu po IP.

nslookup google.com

Sprawdza, czy działa rozwiązywanie nazw DNS.

curl http://localhost

Testuje lokalny serwer WWW na danej maszynie.

curl -H "Host: 12.net" http://localhost

Testuje VirtualHost/ServerName dla konkretnej domeny.

ss -tulpn

Pokazuje otwarte porty i usługi nasłuchujące na systemie.

Usługi systemowe

systemctl status apache2

Sprawdza status usługi Apache.

systemctl restart apache2

Restartuje Apache po zmianach konfiguracji.

systemctl status nginx

Sprawdza status usługi Nginx.

systemctl restart networking

Restartuje konfigurację sieci.

systemctl restart bind9

Restartuje serwer DNS Bind9.

systemctl restart haproxy

Restartuje HAProxy po zmianie konfiguracji.

systemctl restart ssh

Restartuje SSH po zmianach w sshd_config.

systemctl enable apache2

Ustawia Apache, aby startował automatycznie po uruchomieniu systemu.

Uprawnienia, użytkownik i pakiety

whoami

Pokazuje, jako jaki użytkownik jesteś zalogowany.

sudo su

Przełącza na konto root, jeśli użytkownik ma uprawnienia sudo.

chmod 755 katalog

Ustawia uprawnienia katalogu: właściciel pełne, reszta odczyt i wejście.

chmod 644 plik

Ustawia typowe uprawnienia dla pliku tekstowego lub konfiguracyjnego.

chown root:root plik

Ustawia właściciela i grupę pliku na root.

apt update

Odświeża listę pakietów z repozytoriów.

apt install apache2 -y

Instaluje Apache bez pytania o potwierdzenie.

apt install nginx -y

Instaluje Nginx bez pytania o potwierdzenie.

clear

hostname

reboot

free -h
